## 按影响排序的剩余项

### 1. 完整隔离业务闭环尚不能验收

当前安全源码副本不含生产配置、部分初始化/固定账号测试和原始客户样例；项目完整依赖、独立 MySQL 与可运行的锁定浏览器也未就绪。仅安装软件仍不能替代缺失输入和运行权限。

最小步骤：先恢复受支持的隔离运行条件，保持锁定依赖；使用合成配置和合成账号建立独立测试库，不需要线上密码。补足可安全执行的测试输入后，完成“录题→待审核→入库→组卷→定向下发给两学生→作答→正确率→错题→Word导出”的实际 HTTP/浏览器流程，另测未被下发学生不可访问。不能将旧提交的 CI 或本轮 VM 测试当成新版本全套通过。

已确认范围，无需重复询问学科年级：

- 初中数学苏科版：七至九年级上下册，6 册。
- 小学英语译林版：三至六年级上下册，8 册。
- 初中英语译林版：七至九年级上下册，6 册。
- 初中物理苏科版：八、九年级上下册，4 册。
- 初中化学沪教版：九年级上下册，2 册。

每册需要完整章节树和知识点树。除小学数学明确 2024 版外，其余修订年份须以真实来源确认；数学还要求洋葱教师端全部展开，包括思维培优、综合实践。

已有资料核查：需求 Word 提供参考网站和补齐要求，不提供完整逐册目录；物理/化学 JSON 在既有文档中明确为凭印象草稿，不能转正。仓库存在《三上第一单元-教辅资料.pdf》，但 Space 未找到本体，GitHub 文件读取只返回元数据且正文为空，因此未读到封面或目录页，不能仅凭文件名推断其版本和覆盖。没有新增任何一册“完整目录已核实”的证据。

最小步骤：提供可读的原资料/真实导出或连续完整展开截图，保留来源页面、册次和版本年份；先核验一册，再按现有 JSON 规范转换并在隔离库预检。若已有该教辅 PDF，先补可读本体或封面、版权、目录页，不必重找已明确的学科范围。不自行补造知识点。

### 3. 真实采集站样本完整性尚未核实

现有公开列表或合成样本不能证明真实页面的题干、选项、答案、解析、图片和来源完整。既有任务要求各目标页面类型至少 10 道代表题，且需可访问详情；列表不含答案时不能补造。

最小步骤：取得已有教师端可访问条件或用户提供的代表题原文/导出，按页面类型建立真实样本对照，再验字段与来源。第三方登录和验证若需要用户参与，应停在具体动作处，不绕过访问限制。

### 4. 客户 Word/WPS 与真机输入仍缺最终证据

缺可运行环境中的原始 Word/Excel 导入、图片/公式/组合题导出与 WPS 实际编辑/打印证据；移动端中文输入法、公式键盘、扫码及听力还需真实设备验证。结构检查和桌面模拟不能代替这些项目。

最小步骤：先在完整隔离链路中生成一份含代表题型的交付文件，再在获准的 Word/WPS 和真实手机上验证对应操作，记录实际结果。真实试卷 OCR 和已确认的视频不因本项重新启动。

### 5. Ubuntu 上线取决于前述验收和可恢复备份

本轮仅只读确认 Ubuntu 的既有 MySQL 镜像与容器名称，未读取容器配置或连接数据库，未修改服务。最小步骤仍是确认旧代码、数据库、上传文件、私有配置和进程，再备份并验证恢复；在副本演练迁移首次/重复执行和回滚后，才切换新目录服务。不能先清理旧库或覆盖上传文件。

固定初始口令的交付策略、大面板首屏操作建议属于已有待决策事项，本轮不擅自改变；它们不应与已修复的搜索问题混为一谈。
