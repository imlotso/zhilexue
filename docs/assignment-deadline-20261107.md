# 教师重新下发的截止时间与读取失败保护

第八轮独立候选，基线为七轮累计版本，不改七轮冻结包。

发现：下发弹窗不读取/回显已有截止时间；空输入不发送due_at，因此无法取消已设截止。读取原下发名单失败时静默使用空数组，可能导致教师误以为空名单重新覆盖。

实现：通过现有学生选项、已选名单、试卷详情接口共同加载，任何读取失败均显示错误且不打开可提交弹窗。已有截止按本地时间回显到秒，标明清空可取消；未编辑时不发送due_at，保留原始毫秒和服务端最新值；改动后发送ISO，主动清空发送空字符串。无截止未编辑不发送变更。非法输入拒绝提交；非法历史日期明确提示，不伪装成未设置。学生选择逻辑、过滤、后端事务和权限不变。

10条真实前端函数回归，修复前7红3绿，修复后10/10。test:takeover633/633及额外脚本exit0，两JS语法通过。日志 evidence/assignment。未进行HTTP或真实浏览器验收，不声称解决多人同时编辑名单冲突。只复用接口，无模式变更或数据回填。

后续整合审阅补充：datetime-local 会省略为零的秒，比较时已规范化，未编辑的 `:00.123` 截止不会因浏览器省略 `:00` 而重写成毫秒零。新增反例先失败再通过，当前该专项11/11。上述633是更早截止版本的聚合证据，不覆盖之后的最终整合候选。
