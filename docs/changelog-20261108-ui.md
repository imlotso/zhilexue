# 2026-11-08 智乐学概念图 UI 实施

## 本次范围

按用户选定的学习空间、固定答题工作台、后台逐题审核三张概念图实施。开发在独立的安全源码快照进行，不修改运行站、数据库、接口、权限、部署配置或依赖版本。

- 学习空间：增加独立首页，延续原课程、训练、试卷、错题本、主题与账户入口；统计和任务使用现有 API，处理空态、加载失败和过期响应。更多任务入口按真实学科导航，避免将全学科数量误称为目标页全部结果。
- 答题工作台：固定页头和底栏、两列选项、答题卡和桌面 AI 停靠区；手机使用单列答题和可关闭 AI 抽屉。保留全部题型、核对、解析、反馈和结果报告。增加可恢复的 AI 收起入口，修复核对请求结束前切题造成结果写错题的问题。
- 后台审核：深色侧栏、紧凑筛选、题目列表/预览/分类三栏和底栏；保留来源、编辑、图片、AI、合并、批量和分页功能。分类通过原带快照的保存接口持久化；未保存草稿和原服务端审核阻断条件不能绕过。
- 图形：生成并使用同风格的书本插图与共享机器人品牌图；不将概念图示例统计或题目写入生产逻辑。

## 验证与限制

最终测试、截图、逐图对比和已接受的功能适配见项目根 `design-qa.md` 及 `docs/ui-evidence-20261108/`。浏览器测试只使用隔离合成数据和真实前端模块，不调用在线 AI、不登录运行站、不写数据库。真实账户/真实数据库完整业务验收和部署均不属于这次开发交付。
