# 2026-11-08 智乐学概念图 UI 实施

## 本次范围

按用户选定的学习空间、固定答题工作台、后台逐题审核三张概念图实施。开发在独立的安全源码快照进行，不修改运行站、数据库、接口、权限、部署配置或依赖版本。

- 学习空间：增加独立首页，延续原课程、训练、试卷、错题本、主题与账户入口；统计和任务使用现有 API，处理空态、加载失败和过期响应。更多任务入口按真实学科导航，避免将全学科数量误称为目标页全部结果。
- 答题工作台：固定页头和底栏、两列选项、答题卡和桌面 AI 停靠区；手机使用单列答题和可关闭 AI 抽屉。保留全部题型、核对、解析、反馈和结果报告。增加可恢复的 AI 收起入口，修复核对请求结束前切题造成结果写错题的问题。
- 后台审核：深色侧栏、紧凑筛选、题目列表/预览/分类三栏和底栏；保留来源、编辑、图片、AI、合并、批量和分页功能。分类通过原带快照的保存接口持久化；未保存草稿和原服务端审核阻断条件不能绕过。
- 图形：生成并使用同风格的书本插图与共享机器人品牌图；不将概念图示例统计或题目写入生产逻辑。

## 390px 稳态遮挡复核与最小修复

- 确认答题工作台从桌面缩到 390px 时，桌面默认展开的 AI 停靠区会随媒体查询变成固定浮层，持续挡住选项与底栏。现在只在跨入手机断点时收成原有 AI 展开按钮；保留当前题、答案和对话，不请求 AI。手机内高度变化不关闭用户主动打开的抽屉，返回桌面仍保留原有入口与题目核对门禁。
- 学习首页和后台审核侧栏没有持续遮挡。首次 390px、1487/1440→390px、反复跨断点及抽屉开关已用真实前端合成数据验证；200/220ms 退出动画完成后侧栏离屏，正常操作可达。原真实验收截图仅等字体加载，没有等待响应式动画结束，截到了中间帧。因此没有更改这两处生产样式或导航逻辑。
- TDD：新增两项桌面→手机 AI 回归先在旧代码失败，最小修复后通过；覆盖保留答案、选择与提交按钮可点、锁定 AI 展开不调用服务、跟随切题、最小化/关闭、手机高度变化以及返回桌面。
- 验证：`npm run test:ui-concepts:unit` 11/11；`npm run test:ui-concepts:browser` 18/18（学习 5、答题 11、后台 2）；`npm run test:takeover` 退出 0；生产 JS 与改动测试的 `node --check`、`git diff --check` 通过。浏览器使用 `/usr/bin/google-chrome`，测试进程通过既有 safe-test-preload 阻断数据库初始化、私有配置读取与运行站端口；只运行隔离合成前端 fixture，未启动业务服务、连接数据库或复跑真实业务写入链路。
- 稳态合成截图归档在补丁工作目录相邻的 `20261108-ui-mobile-overlays-evidence/`，相对路径：`evidence/ui-quiz/quiz-resized-{1487,1440}-390.png`、`docs/ui-evidence-20261108/learning/learning-stable-{390,1487,1440}-390.png`、`docs/ui-evidence-20261108/review/review-stable-{390,1487,1440}-390.png`。这些为本地验证产物，不是生产数据；真实候选定向复验与部署由集成负责人继续。
