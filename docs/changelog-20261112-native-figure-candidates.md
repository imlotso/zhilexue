# 原生PDF图块候选框（2026-11-12）

## 范围
这是人工裁图提效，不是自动题图归属或全自动识别。仅新上传PDF，浏览器pdf.js按原始绘图矩阵定位普通嵌入图像对象；不使用视觉模型猜坐标，不推断题号。小于4pt的对象、超过页面65%的整页扫描图被过滤。复杂group/mask/repeat不猜测；矢量图、文本标签、图外说明和组合图可能遗漏，path/form clipping未完整解析，候选框也可能包含不可见区域。老师必须看原页，可重新拖框。

## 数据与安全
- 页图记录新增figure_candidates（normalized x/y/w/h），服务端仅接受有限数值、页内正矩形、最多200项，去重并丢弃URL、题号等额外字段。
- 候选只跟随该页上传并包含在既有请求指纹中；不写题卡figures，不设置确认签名、不入正式题库。
- 原页API按当前批次提供候选。裁图弹窗需明确选择候选，再由用户点保存；仍走已有图号/替换确认/题图归属确认门禁。
- 旧批次、图片上传、候选提取失败均继续原有人工框选。旧生产数据不回填、不修改。

## 验证
- 同一用户PDF仅在隔离本地解析：7页23候选，分布6/7/4/2/3/1/0；逐框与独立PyMuPDF原生几何比较，最大归一化误差4.62e-8。真实Chromium调用PDF转页图路径，23框及缩放后坐标一致。原文件SHA256核验一致，原文/图片不入仓库。
- 原生几何单测含矩阵save/restore、form、旋转、极小/整页过滤、非法输入边界。6项UI行为测试覆盖不自动保存、手动回退、切页晚到响应、图片失败、替换确认竞态。
- 桌面900px/手机390px浏览器验证实际canvas输出60×80PNG，仅点击保存发POST；该UI截图是明确合成数据，不是生产验收。
- 隔离API验证候选元数据上传与读取、额外字段剥离、不会设置figures/确认签名或绕过缺图入库；原有上传回执/幂等与跨页OCR回归通过。

最终验证结果：47项unit全部退出0；image-review-flow-test.js、import-receipt-flow-test.js、recognition-pages-flow-test.js三项隔离API通过。独立审查通过，边界负宽问题先红后绿修复；未部署生产。
