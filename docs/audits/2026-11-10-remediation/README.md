## 历史数据和兼容性

- 新增 `report_uploads` 和两类尝试的可空 `total_score_snapshot`，全部幂等新增，不删表/列或回填猜测。
- 旧试卷明细可能只含已答题，不能用其分值和猜原卷满分。新交卷同事务保存整卷满分；人工评分和后续改卷不改变该快照。旧NULL显示“满分未记录”，保留得分，不编造百分比。
- 旧无主成绩库保留原位，不自动归属给下一个登录账号。已从未保存或被覆盖的历史错词无法凭空重建，只恢复仍存活的可辨识记录。
- 未验证或被共用的旧报告附件不会被删除；返回保留/清理失败信息。旧报告重试需重新上传可验证附件。
- 不声称实现整套试卷不可变历史模型。现有内容编辑仍存在；本轮保护已确认的破坏性删除入口，并为新尝试保存满分快照。
