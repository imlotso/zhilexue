# 智乐学代码与使用体验审查

日期：2026-11-10。基线：[实际main 4f60b7a](https://github.com/imlotso/zhilexue/commit/4f60b7a9bdc5015323308a21a30dfa76e408c0c8)。先确认main提交，再取得该版本、隔离部署与重跑；候选6f9505f不作为最终基线。

## 结论
主业务API流程能够完成，但不建议把“流程通、CI绿”理解为数据与权限安全已验收。共记录20项问题/风险：P1六项、P2十三项、P3一项。2项已在实际HTTP应用和独立SQL库复现，12项使用实际源码加VM/jsdom/内存边界复现，6项为源码审查或算术推导。没有执行生产漏洞利用。

最先处理：
1. **I1/P1：入库静默吞掉数学不等式。** “若 1 < x < 3 且 y > 0，求 x+y。”保存后成为“若 1 0，求 x+y。”。
2. **I2/P1：选项重新编号、答案未同步。** 清空中间B选项，原正确C显示为B，答案仍C；学生选择正确B，真实接口判错。
3. **B1/P1：报告附件删除缺少规范目录和归属边界。** 静态发现，未执行破坏性删除，实际生产文件权限未验证。
4. **B2/P1：旧报告接口缺分校学生归属限制。** 新报告有保护，旧路由仍不一致。
5. **B3/P1：视频列表/文件通道与正常播放的可见范围不一致。** 只审权限，不推翻已验收的播放交互。
6. **F7/P1：共享浏览器的成绩缓存未隔离账号。** 登录校验失败仍能显示前一账号的本机成绩，不是API越权结论。

其余包括：成绩保存失败无提示、家长扫码“提交成功”但未送达教师、无逐题证据的知识点诊断、异步页面串数据、错词历史丢失、统计遗漏、删题损坏已有试卷、数据库提交断线窗口，以及旧兼容入库入口的原子性缺口。详见[逐项发现](findings.md)。

- 本地81个CI命令组：**54组通过，4组仅非浏览器部分通过**；16组浏览器阻断/跳过，3组原始样本测试未运行，2组网络探测未重试，2组云配置测试因无真实云配置被阻断。部分通过命令内部还有明确跳过项，不宣称81组全绿。

### 真实浏览器限制
本地Chromium启动需要的Unix socket被环境禁止；可用云浏览器也无法访问隔离服务的回环地址。没有绕过限制。500px公式弹窗只完成静态宽度和DOM生命周期测试，MathLive键盘使用替身；**真实500px布局、展开收起、软键盘遮挡和截图未验证**。现有公式浏览器用例仅390/1440两尺寸。

### 环境和样本限制
本地为Node 24.22.1、MariaDB 11.8.6（MySQL协议），不是生产MySQL版本。试卷及部分测试用自造十题Word/已发布空白模板替换私有需求样本，仅验证功能，不验证原始样本一致性。第一次隔离部署漏带内置模板/知识树已补齐后重新全库测试；合成试卷首次题型分段不符合原测试夹具，改用同结构合成题后54/54。原失败日志没有被当作产品bug或隐去。

## 哪些地方不够人性化
- 保存、提交、AI完成提示必须对应真实成功：重点修F8/F9/F6和B8，失败要可见、输入要保留，并给重试方式。
- 页面切换与账号切换要停止旧请求、清空旧缓存：F2/F3/F4/F7。
- 教师核对后应所见即所得：优先修I1/I2；未有逐题证据时不要生成看似准确的弱项诊断（F10）。
- 弹窗键盘事件不能落到背景练习（F5）；错词历史应稳定可追溯（F1）。
- 已有改进不重复报bug：新批量入库提供逐题失败清单；快照+事务主路径可回滚；专门“删除选项”按钮已有答案重映射。
- 不建议现在全站重做UI。先修上述可信度和数据闭环，再用真实500px设备验证布局。

## 性能与依赖
待审核多处先读取全历史JSON后筛选分页；同步数据库桥通过Atomics.wait阻塞主线程。这是规模风险，未压测，不给虚构的耗时/并发上限。建议先测P50/P95、查询次数和读取字节，再做定向查询、SQL分页、批量写入。

本轮经明确授权后向npm官方registry完成生产依赖公告匹配：body-parser、ws、xlsx、qs四项（3高、1中、0严重）；业务可达性不等同于已利用。首次未授权请求被阻止，授权后只重试一次并取得结果。没有升级依赖或运行audit fix。详见[依赖与优化说明](dependencies.md)。
