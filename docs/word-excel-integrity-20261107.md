# Word / Excel 导入保真修复与验证（2026-11-07）

本次在既有安全源码候选的独立副本上验证，不连接真实数据库、生产存储、外站或识别模型。没有提交、推送、合并或部署。原客户模板文件未修改。

## 修复内容

- DOCX 文本抽取不再将 `w:tabs` / `w:tab` 误当正文标签吞掉文字；纯文本文档不要求可选的关系文件存在。支持数值 XML 字符实体及成对/自闭合换行，保留原空白语义。
- 嵌入图片的关系属性顺序、单/双引号、包内绝对/相对目标路径均可识别。支持 DrawingML 和常见 VML 图片，Choice/Fallback 选择一个表示，独立图片仍分别保留。有内嵌缓存时优先使用缓存，不因前置外链误判缺图；不请求外链。
- 图片保存失败或包内媒体缺失时保留原图号空槽，由待审核/课文导入入口明确拒绝，避免静默删图或使后续图号前移。原本题目引用的答案图、解析图和共享材料图均保留；进入待审核时，题干、选项、答案、解析统一转换成本题图号。
- 课文 Word 无题型标注的编号题不再丢题干。混合有/无题型标注的题目根据明确的答案/选项分题，缺答案且无选项的混合题目须显式注明题型，不再让后一题答案覆盖前题；明确标注的同号题优先于解析中的编号步骤。仍然是约定格式解析器，不是任意 Word 文档的结构识别器。
- Excel 选词填空以一组开始的物理行定位词库，相同说明的不同题组不串用答案；特殊文本不会触发对象原型键错误。错误位置使用真实工作表行号，空行不导致错报。旧 Excel 入口保留数值 `0` 答案与选项。

未改变接口路径、响应协议、权限或数据库结构。两个新增回归已加入 CI unit 任务。
