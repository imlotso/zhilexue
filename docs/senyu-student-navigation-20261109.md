# 学生侧栏导航统一

## 变更范围

- 保留“学科导航”和“学习工具”两个分组，以及现有路由和业务方法。
- 所有导航行统一为 18px 字号、至少 48px 高度、24px 图标（28px 容器）、12px 间距和同一内边距。工具文字不再使用更浅、更小的样式。
- 统一悬停、键盘焦点与当前项反馈，悬停填充区别于白色和护眼/绿色主题的薄荷侧栏背景，添加 `aria-current`；再次点击当前页面也会收起抽屉。关闭时只归还抽屉或其遮罩持有的焦点，不抢其他页面控件的新焦点；关闭后的入口通过 inert、aria-hidden 与 visibility 从键盘和辅助技术中隐藏。
- 新增独立 `senyu-student-navigation.css`，仅作用于森屿学生抽屉，在共享样式之后加载。更新学生 JS 缓存版本。

## 根因与优先级

旧学习页样式为主导航设置了 `23px!important` 和 61px 行高，平板又设为 `20px!important`；工具入口独立使用 15px、37px 和浅色。后加的 `.rounded-student .st-subj a` 选择器优先级不足，不能覆盖旧字体规则。

新适配层对两组入口使用完全一致、限定作用域的选择器。回归测试同时加载学生入口的全部真实样式，确认旧规则确实存在，并校验新规则的 `!important` 和选择器优先级，避免只验证新文件中存在 18px。

## 验证方法与边界

`senyu-student-navigation-test.js` 挂载真实 Vue 抽屉模板与原路由方法，使用合成学生状态，无数据库或真实账号。检查分组、图文结构、样式、同页关闭、原路由、当前项、错题数量和完整 CSS 优先级。

`senyu-student-navigation-browser-test.js` 为实际浏览器验收准备 1440、1024、390px 场景，加载生产入口全部 CSS 与真实 Vue、合成离线数据。检查布局尺寸、文字对齐、悬停、Tab/Enter、同页关闭和横向溢出。设置 `SENYU_EVIDENCE_DIR` 可保存截图。

焦点增量补充了同页/新页路由、load()、关闭按钮、遮罩、Escape/输入法、外部焦点与快速重开保护，以及返回按钮被 CSS 隐藏时的回归。新增失败用例确认问题后修复。导航 13 项；与既有学生、API 生命周期和当前分支共享 UI 联合回归共 55/55。JS 语法与差异空白检查通过。测试入口由全站集成分支统一维护。
