## 0. 结论先说

| 类别 | 条目 |
|---|---|
| **完全没做** | 知识树「教材版本」维度；洋葱式多层数学树（小学 + 初中）；物理 / 化学的树（一棵都没有）；题目挂到「小分组」；组卷网式组卷界面；课程页右上角显示正确率；答错后 AI 解析在右下方显示；课程页知识点关联视频和知识点树；菜单调整与学情报告合并（BOBO 11-04 新要求）；老师端扫码录题 |
| **做了但没达到预期** | 网络采集（方案脆弱、书签坏了、采不到答案 / 图 / 公式、有安全漏洞）；录题入口分散且一半绕过待审核；所有上传界面风格不一、丑；题库列表选项显示 `[object Object]`；做题弹窗高度跳动、题图只有 42px 高；学习报告「详情」404；成绩管理 / 家校沟通是 iframe、风格割裂；真题导入不挂知识点；英语只有"音频附加"，没有完整题型 |
| **基本满足（只需打磨）** | 待审核页主体、知识树编辑页、学生端「我的任务」/ 自组卷 / 试卷库、错题 Word 导出、公式键盘、单词页固定布局、手机视频播放基础 |

**这一轮的原则**
1. **截图就是验收标准**：凡是文档里有截图的页面，做完要能和截图对得上：结构一致、交互一致，视觉沿用我们现有的设计语言（T11 的 `theme.css` 变量、主色 `#1E88E5`），再在此基础上优化。
2. **每改一个页面就给出页面路径**，并给出改前 / 改后截图，方便 BOBO 在测试环境逐页对比（第 9 节有总表）。
3. **每个功能都要完整测试**：接口测试、浏览器实测（桌面 1440 + 手机 390），能自动化的加进 CI。
4. **先修 bug，再改结构，最后美化**。

## 1. 需求逐条梳理（原文 → 理解 → 现状 → 差距）

### 1.1 智能题库 · 题目管理：知识点分类再次细化（图1–图3）
- **原文**：数学按照洋葱教师端，英语、物理、化学参考组卷网和 21 教育网的知识树逻辑，**把所有的补齐**，并且我可以自行添加和编辑知识树。分两种：一个是章节的，一个是知识点的。
- **截图含义**：图1 是我们题库管理左栏（红框）；图2 是洋葱（顶部选「小学 / 数学 / 苏科版（2024）」，下面是 单元 → 小节 → 知识点 的多层可展开树，另有「思维培优」「☆综合实践」等分支）；图3 是 21 教育网英语（教材版本标签 + 册别标签 + Unit 列表）。
- **BOBO 补充（11-04）**：数学题库小学、初中都要；按洋葱课堂来做。
- **现状（实测）**：
  - 树结构是「一个 学段 + 学科 只有一棵树」，**没有教材版本这一维**，版本写死在树名里。题库管理用 `trees.find()` 只取第一棵（`public/admin/mfui2.js:38-39`），建了第二个版本也选不到。
  - 现有数据：苏科版数学章节树（小学 3 层到「单元」，初中 4 层到「节」）、译林版英语；**数学知识点树只有 2 层**（小学 18 个节点、初中 40 个）；**物理、化学、高中一棵都没有**。
  - 课程目录用的是「人教版」，题库章节树却是「苏科版」，两者对不上。
  - 左侧树的节点题数不含子节点（`src/mfbank.js:137`）；树行布局错位（`public/css/app.css:3423` 的 `flex:1` 同时作用在箭头上）；鼠标悬停在已选中的切换键上会出现蓝底蓝字（`theme.css:186-187`）。
- **差距**：数据和结构都没做，界面也没按图2 做。

### 1.2 优化录题（图4–图7）
- **原文**：可以快速上传题目；多种录题方式都需要，目前有的也不完善；英语要有听力题；技能包转化后导入；题目上传后不能自动打好标签；**批量录入后先进待审核，一个个能看到再入库**；现在感觉很乱；英语题型不够完善；数学公式编辑器和图片不够友好。参考系统 1（Qrane，图5）、2（yiguodu，图6）、3（魔方助教，图7）。
- **BOBO 补充（11-04）**：题库管理里**反馈上传的 UI 很丑**；**网络采集有很大问题，很多功能达不到预期**。
- **现状（实测）**：
  - 录题入口散在 6 处以上：题库管理「导入题库」只收技能包、「新建题」直接入库；待审核页导入 Excel / Word；`#/mfi` 录题上传（拍照 / PDF / Word → 工作台，**入库绕过待审核**）；`#/mfc` 网络采集（试题篮入库**绕过待审核**）；试卷管理上传真题（**直接入库**）；课文习题批量上传（**直接入库**）。`#/mfc`、`#/mfi`、错题反馈**不在左侧菜单**，只在题库管理顶部三张卡片里。
  - 待审核页：单题「入库」**不弹分类**，能入空学科的题（实测入了一道 subject 为空的题）；编辑弹窗**没有选项输入框**。
  - 题型只有 6 种：单选、多选、判断、填空、排序、解答。英语**没有听力、完形、阅读、选词填空、句型转换、作文**等独立题型；听力只是给题目附加一段音频。
  - 上传界面：录题批次弹窗字段不齐、没有拖拽区、要两步；工作台 9 个按钮风格不一，识别失败时没有任何提示；待审核导入弹窗只有 3 个下拉加一个按钮，无拖拽、无预览；「导入题库」弹窗要老师先装 AI skill，门槛极高。
- **网络采集（`#/mfc`）逐项实测**，问题如下，详见审计 N-1 至 N-18：
  1. **书签采集是坏的**：回传地址写成了后台接口 `/api/admin/bank/mf/capture/push`（`src/mfbank.js:660`），用采集票据调用实测 **403**，而且失败后会**清掉本地票据**（:714）。正确的 `/api/mfcap/push` 实测可用，但脚本没用它；后台接口也没有 CORS，https 页面调 http 后台还会被混合内容拦掉。
  2. **方案本身脆弱**：靠服务器代理打开组卷网等站点再注入悬浮球。服务器 IP 被对方拦截时页面一片空白、没有任何提示；登录态只存在服务器内存里，重启就丢；全员共用一个出口 IP，被封一次所有人都受影响。
  3. **采集质量差**：只认组卷网、菁优网的特定 CSS 类；题号和选项拼进题干，选项重复错乱；**答案、解析永远是空**，**不采图片**，公式被压成纯文本。
  4. **采知识树会产生孤儿树**：学段、学科为空，题库里选不到。
  5. **安全漏洞**：代理 iframe 同时带 `allow-scripts allow-same-origin`，第三方页面能读到校长的登录令牌（实测可读）。
  6. **入库绕过待审核**，只选学段 + 学科，没有年级、章节、知识点。同一批题在试题篮、暂存批次、待入库、待审核四处各出现一次，状态不同步。
  7. 导航错乱：「返回」「返回组卷」都跳到智能组卷页；悬浮球实际在右上角，提示却写在右下角。

### 1.3 智能组卷（图8–图11）
- **原文**：老师从题库**按知识点或章节组卷**，筛选好题目后下发给单个或多个学生，学生在「试卷 - 我的任务」查看并做题。学生端也能自己组卷，就是试卷页里的「章节组卷」和「知识点组卷」，这两个要做区分。管理端是汇总功能，唯一不同是老师可以下发。**组卷参照二一组卷网**（图10、图11）。
- **BOBO 补充（11-04）**：**都要按照 Word 里的截图来做筛选界面**，保留现在的设计语言并做优化，改过的页面要给出页面路径。
- **截图含义**：图10、图11 是组卷网「章节选题」。左侧是教材章节树（版本 · 册别，章 → 节，可折叠）；右侧顶部是**标签式**筛选（题型、来源、难度、方式（关联出题 / 精准出题）+ **已选知识点复选框组**、学科素养、命题特征、更多：题类 / 适用年级 / 地区 / 年份）；下面是**题目列表**，每题带难度、组卷次数，可「+ 选题」放进**试题篮**；顶部有「章节选题 / 知识点选题 / AI 组卷 / 试卷库」等页签。
- **现状**：后台 `#/paper` 是**纵向表单**（标题、学科、学段、年级、册别、范围下拉、平铺复选框树、题型数量、一键组卷），只能随机抽题后再删，**不能浏览题目逐题挑选**，没有试题篮，没有标签式筛选，也没有「已选知识点」条；学生端自组卷估算的"约 N 题"是叶子数而不是真实题量，而且必须先选学科。

### 1.4 试卷管理（图12–图14）
- **原文**：上传真题试卷，题目同时进入题库；学生端可以搜索并直接做题。
- **现状**：基本功能有，但只收 `.docx`（不收 PDF / 图片）；导入的题**不挂章节和知识点**（无法按知识点组卷）；不进待审核；试卷库只能搜卷名和年份。图13 的 21 教育网试卷详情（预览、类型、学段、版本、地区标签、同类资源）没有参照做。

### 1.5 课文习题（图15–图18）
- **原文**：视频可以挂载习题，**也可以挂载到小分组**（比如混合运算与数量关系），所有题目都要进题库管理；挂载后学生端对应显示；做题框做成固定大小（字多字少不跳动），要有公式输入法，英语要有听力，框要美化；做完题要有学习报告；进度要**添加习题正确率**（单个视频及小分组）。参考 aiwenweike（图17）、xiaoyeoo（图18）。
- **BOBO 补充（11-04）**：
  - 学生端课程页的「知识点」要能**关联上视频和知识点**；
  - **右上角进度也要显示正确率**；
  - 答错题点 AI 解析后，结果要**在当前窗口的右下方显示**；
  - （见 BOBO 截图）做题弹窗里题干图片小得看不清。
- **现状（实测）**：
  - **题只能绑视频，不能绑小分组**（`questions` 没有 `section_id`），小分组正确率是组内视频的题合并算出来的。
  - 课程页的「知识点」其实是课程目录的小节（sections），**和题库知识点树没有关系**，看不出一个视频讲的是哪些知识点。
  - 右上角只显示「进度 0/7」（`public/js/vue-app.js:802-805`）；正确率放在下面「知识点」标题旁的灰色小字里。
  - 做题弹窗桌面端**高度随内容变**：作答前 536px，判分后 750px，弹窗整体上移 107px（`app.css:3062` 只设了 `max-height`）。
  - `[图N]` 占位的题图**固定 42px 高**，700×500 的图被渲染成 58×42（`app.css:3646`）。
  - 「AI 老师分步讲解」**另弹一个居中小窗盖住题目**，只能一步步追问，看不到完整讲解；失败时只有一行灰字。
  - 后台「管理习题」弹窗不渲染公式和图片。

### 1.6 管理后台：学情报告 / 首页 / 学情管理 / 整体 UI（图19、图20）
- **原文**：优化学情报告和首页；学情管理里的成绩管理是单独做的，融进来格格不入；各模块的按钮乃至整个后台 UI 都重新设计。
- **BOBO 补充（11-04）**：
  1. 「知识点正确率」本身就是「学习报告 → 习题学习报告」，**两者合并**，知识点正确率页里新增的「导出错题 Word」挪到习题学习报告页；
  2. 「学习报告」**移到「学生与账号」下、「学生管理」后面**；
  3. 「AI 学情诊断」**放到「家校沟通」下面**。
- **现状**：菜单还没调整；**视频 / 习题学习报告每行的「详情」按钮 404**（前端少了 `/detail`，`reportui.js:190,277`）；成绩管理、谈心谈话、家校沟通都是 iframe，一个页面里有两套导航、两套配色；首页没有学情概览和待办；还有 emoji 与线性图标混用、按钮三四种风格并存等问题。

### 1.7 错题本（图21、图22）
- **原文**：页面优化，做得好看；**取消收藏**；拍照上传题目走手机扫码，进入题库管理的待审核题目，**要有标注**；拍一张照片后 AI 直接识别错题并做好分类；错题打印成**可编辑的 Word**。图21 是参考（仅打印题目 / 打印题目和解析），图22 是上传错题（单题 / 跨页题 / 多题拆分 + 拍照建议）。
- **现状**：版面已重做，收藏已取消，扫码上传和 Word 导出都有；但**没有跨页题、多题拆分**，图上不能**圈出 / 标注错处**；Word 里的公式是 LaTeX 源码；默认停在「英语」学科（即使英语没有错题）。

### 1.8 客户额外要求（客户额外要求.png）
后台 UI 不好看（并入 1.6）；题库和视频分离存储（T12 只做了前缀隔离，**要不要真分桶请 BOBO 确认**）；设置里的 AI 接口有点乱（AI 配置中心弹窗里还残留"五个角色""R1 推理"等旧说法，「字典 / 树映射」也混在这一页）；学生端单词页固定大页面（基本满足）；手机端视频播放（真机待验证）。
