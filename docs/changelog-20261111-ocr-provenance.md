# 全自动逐页识别证据隔离修复（2026-11-11）

## 现象与边界
生产隔离批次的一份七页化学卷（23题号）输出39张卡，8至23号重复，尾页续行被扩写为整题。第13题不同页卡的选项冲突，不可简单保留首卡去重。只读核验39卡figures均为空，无images/bbox；本次不声称自动提图已解决。

## 根因及修复
- 旧链每次向模型发送前一页与当前页两张图片，同时带上前页题干和材料全文，容易复读前页、用旧内容补全当前页缺失。
- 改为仅当前页视觉证据，保留前题号和材料标识元数据，但不提供此前原文。明确缺选项、续行只能照抄可见片段。
- 不添加危险的题号首项去重，不覆盖旧批次；既有CAS并发保护、逐页成功保存、失败保留仍在。
- 空结果仍报错可重试，不让模型一句no_questions将页面锁成已完成。
