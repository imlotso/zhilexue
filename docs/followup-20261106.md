## 核实的缺口与本次改动

| 实际缺口 | 处理结果 |
|---|---|
| Word 不接收听力排序、连词成句的细分题型，最终落成问答题 | 保留排序基础题型、连续选项和明确答案序列；答案缺失留空，重复或越界序列报错。 |
| 学生排序组件读取的打乱结果结构与函数返回值不一致，候选词块为空、序号为 NaN | 统一为词块及原始位置对象，浏览器实际按顺序点选并核对提交序列。 |
| 阅读、完形、还原、选词、对话、改错的细分标签不完整 | 新增对应标签；阅读、任务型阅读、对话允许按实际题面使用选择、填空或问答，问答由老师评分。原有听力、词句、翻译、写作功能继续复用。 |
| JSON 明确基础题型会被细分题型的默认基础类型覆盖 | 优先保留明确基础题型，不兼容组合报错，开放式阅读/对话保持问答。 |
| JSON 组合题丢失共用音频与次数 | 继承已上传的题库音频 key 和 0–5 次配置，小题显式设置可覆盖；无效 key/次数明确报错。不下载外站音频，也未实现 ZIP 内音频资产转存。 |
| Word 普通选择/填空题缺少明确的共同材料输入格式 | 增加独立行 `[材料]`、`[材料结束]`、`[材料清空]`，各题保留材料、图号及同组顺序，不猜测未标明的任意文档结构。 |
| 扩展模板缺少开放题和英语细分说明 | 英语扩展模板增加问答工作表及题型说明，客户原始模板不变；Excel 问答支持细分标签并人工评分。 |
| 传输没有统一超时，离页回调访问旧页面，中断后容易直接重复上传 | 文件上传共用 120 秒超时和结果未确认提示；Excel/Word/技能包连接中断后阻止当前页盲目重复提交，提醒先检查批次；已完成的页图和题卡可从批次继续。 |
| 手工和粘贴 JSON 页面离开后输入丢失 | 当前账号、本标签页暂存文字草稿；手工恢复学科、材料、小题、细分和音频设置；JSON 输入保留。浏览器限制存储时不能保证恢复，不保存本地文件内容。 |
| 识别/转写循环失败只短暂提示，停止按钮会被重绘替换 | 展示持续错误信息；全自动恢复跳过已完成页，转写跳过已有文本；当前页保存后暂停。保存题卡失败时保留编辑区并恢复按钮，不进入后续识别。 |
| 七种入口的恢复说明不一致 | 录题中心、图片/PDF、Excel/Word、技能包、手工、扫码和采集接入共用教程/恢复提示；各入口保留原有适用操作。手机宽度下的手工底部按钮不再竖排。 |

## 剩余边界和外部缺口

- 恢复以已保存批次/页面和本标签页草稿为单位；不支持文件字节级断点续传，也不是关闭浏览器后继续执行的后台任务队列。结果不确定时须先检查已有批次。旧工作台的直接追加文件入口仍沿用既有上传器。
- 自动判分沿用现有规则：填空/翻译对照老师提供的参考文本和备选，未新增语义等价判定；开放问答、写作由老师评分。听力次数是本次练习界面的限制，不是服务端防绕过的考试播放额度。
- JSON/ZIP 内本地音频文件的自动转存、任意嵌套组合题及无标记 Word 的自动材料关联仍未完成；音频可在待审核上传，复杂题组可用材料加小题方式录入。
- AI 生成答案、解析继续作为独立建议，老师须分别确认后才能进入正式字段。本次未调用真实 AI，不对真实识别准确率作结论。
- 教材目录、知识点和外站采集缺口沿用 `pending-human-actions.md` 的 R2/R5 清单：需要已确认版本各册的真实目录、知识点导出或完整截图，以及可登录的老师端和代表性题目页面。演示树、草稿不算完整目录。
- 真实手机扫码、iOS Safari/微信/Android 的键盘与音频行为、WPS 实际打开和编辑导出文件，需要对应设备/环境与客户材料。此次为桌面 Chromium 响应式检查，未冒充真机或 WPS 验收。
