## 附：知识树 JSON 格式（`zhilexue-tree` v1）

一个文件可以是单棵树对象，也可以是多棵树组成的数组。

```json
{
  "format": "zhilexue-tree",
  "version": 1,
  "kind": "textbook",
  "subject": "数学",
  "stage": "primary",
  "edition": "苏教版",
  "name": "苏教版数学·教材章节",
  "source": "yangcong:2026-11",
  "nodes": [
    { "name": "三年级", "children": [
      { "name": "上册", "children": [
        { "name": "一 混合运算与数量关系（一）", "children": [
          { "name": "混合运算与数量关系", "children": [
            { "name": "混合运算与数量关系" },
            { "name": "列算式解决问题" }
          ]}
        ]},
        { "name": "☆一天的时间" }
      ]}
    ]}
  ]
}
```

| 字段 | 说明 |
|---|---|
| `kind` | `textbook`（章节树）或 `knowledge`（知识点树） |
| `subject` | 数学 / 英语 / 物理 / 化学 |
| `stage` | `primary`（小学）/ `junior`（初中）/ `senior`（高中） |
| `edition` | 教材版本：苏教版 / 苏科版 / 译林版 / 沪教版；知识点树可留空 |
| `name` | 树名，例如「苏教版数学·教材章节」 |
| `source` | 来源，例如 `yangcong:2026-11`、`zujuan-xkw:2026-11` |
| `nodes` | 节点数组，每个节点 `{ "name": "…", "children": [ … ] }`，没有子节点就省略 `children`；可选 `code`、`note` |

**章节树的顶层**请用「年级 → 册别」两层（例如 三年级 → 上册），下面再接单元 / 章。
**名称**照网站原文抄，包括序号（一、二…）、☆、括号等。
**导入**：同一棵树分多个文件导出也没关系，我们按路径合并，同名同位置的节点不会重复。
