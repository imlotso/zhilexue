# 后台四页圆润 UI：逐图核对与保留交互

日期：2026-11-08。范围：逐题审核、智能组卷、学情报告、多方式录题中心。未提交或合并代码，未连接真实数据库，未改动运行中的 3000 服务。

## 核对方法与总体结论

逐对查看批准的 05、06、08、10 PNG 与最新实际 Chromium 截图的像素。截图由生产页面组件、生产样式、离线合成 fixture 生成，不是真实学生学情。浅薄荷侧栏、深绿胶囊导航、暖白底、大圆角白卡、浅绿工作区和黄色主按钮形成可见的结构变化，而非仅换色。保留原有流程导致部分布局与示意图不同，不声称像素完全一致。公共导航、顶栏及品牌由公共 shell 变更提供。

## 05 逐题审核

参考：05-逐题审核.png。对应：ui-evidence-20261108/review/admin-review-1487.png。

- 已实现独立的待审队列、题目预览、分类信息三栏圆角工作区，队列来源标签、薄荷提示区、底部单题核对区的层次与参考一致。
- 保留实际来源/批次/状态筛选、分页、高级工具、题目编辑和字段来源提示。生产数据可能比示意图更长，预览与分类内部滚动，未裁去功能。
- 保存分类与核对入库仍是两个独立操作。未满足校验条件时入库按钮按原规则禁用，不为了模仿参考中的黄色按钮而解除保护。
- 低高度桌面使用紧凑布局，分类保存按钮固定在分类面板顶部。该位置有意不同于大屏参考，保证短屏可见；手机仍按原断点堆叠。

## 08 学情报告

参考：08-学情报告.png。对应：ui-evidence-20261108/rounded-admin-pages/report-1487.png、report-detail-1487.png、report-subjective-pending-1487.png。

- 列表改为圆润学生卡片，保留查询、导出和可展开原始明细表。详情用知识树与学习反馈双卡片呈现，沿用浅绿/暖黄分区。
- 原系统是学生列表进入详情抽屉，继续保留该交互，而非把示意图的单学生全页布局强行替换。原主观题、试卷和导出入口没有移除。
- 未作答、零正确率、已有作答待人工评分分别展示，不把缺失准确率转为 0%。知识点与统计来自现有 API，没有虚构学习进度。
- 空 last_at 的列表文案精确为“暂无可统计的客观题或试卷记录”；仅主观题或试卷待评时详情显示“已有作答，等待人工评分”。独立复核已关闭该 P2，未修改 API 统计口径。

## 768px 高度回归证据

新增 ui-rounded-admin-review-height-test.js。在 1366×768 与 1024×768 实际 Chromium 中验证编辑、保存分类、核对入库三个控件均在视口内且中心点击位置未被遮挡；打开关闭题目编辑、修改分类并保存、展开高级工具后再次检查均通过。

修复前实测工作区底部为 826px、底栏底部 810px、分类保存底部 872px，超出 768px。修复后两个视口的工作区从 y=66 到 y=768；底栏底部 756px；编辑按钮底部 664px；分类保存底部约 359.4px；入库按钮底部 744px。分类表单保留内部滚动。截图：review-compact-1366-768.png、review-compact-1024-768.png；详细几何：review-compact-geometry.json，均在 ui-evidence-20261108/rounded-admin-pages/。
