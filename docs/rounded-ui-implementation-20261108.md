## 十页覆盖

1. 学生首页：顶部导航、深绿学习hero、真实任务和自主练习卡，保留其他功能菜单。
2. 课程：主学习卡和右侧单元/课时结构，保留原视频弹窗、小分组及知识点入口。
3. 答题：白色页头、深绿进度、琥珀提交、圆角题卡/答题卡与原AI门控，适配填空/选择、长题、40题、重练和响应式。
4. 后台首页：薄荷侧栏、教学hero、常用操作、工作入口、真实汇总和题库组织。
5. 审核：待审队列/题目/分类三卡，保留编辑、分类保存、单题核对、批量和入库限制；补768高屏适配。
6. 组卷：树/列表/常驻深绿题篮；所有数量分数来自QB，实际编辑保存仍由原预览弹窗处理。
7. 错题：实际错题卡、筛选、折叠解析、重练和真实Word范围导出，保留上传审核、复习和历史。
8. 学情：学生统计卡和详情双区，保留原抽屉/全部统计字段；无数据与仅主观题待评有准确文案。
9. 手机：首页与固定底部导航，空任务单行，两项自主练习不被底栏遮挡。
10. 录题：Word主入口、实际原向导、准备提示、全部原录题方法及批次；真实生成的文档图片。

三张新增透明PNG分别用于学习首页、后台首页与Word录题主区。原品牌和本地图标继续复用。生产无硬编码示例学生、题量、成绩或日期。

## 与图稿刻意保留的差异

UI改变不等于重做业务流程。课程仍原播放器弹窗；录题设置/上传仍原向导；组卷标题/时长/顺序/分值在预览弹窗；学情详情仍抽屉；错题导出仍原范围选择；答题保留原数字键盘与MathLive公式弹窗。后台首页用现有权限内汇总，不制作缺少接口的学生选择器。详细逐图验收及全部已关闭问题见根目录 `design-qa.md`，学生/后台分项报告见同目录 rounded-student/admin-pages 文档。

## 最终验证

所有浏览器检查使用系统 Google Chrome（Playwright1.62.1），真实前端组件＋受控合成数据，不以源码测试代替实际浏览器。

- `npm run test:ui-rounded:unit`：13/13，0失败/跳过。
- `npm run test:ui-rounded:browser`：21项＋原审核2项，共23浏览器子测试，0失败/跳过。覆盖1487、1440、1366、1024、820、390宽度，768高短屏及桌面→手机切换。
- `npm run test:takeover`：33个命令组退出0。其中28组TAP共749项；另外5个自定义脚本共58项，单独计数，不把内层断言重复相加。部分脚本明确是源码/fixture检查，不称为生产端到端或全部浏览器。精确展开表见学生实施报告。
- 学生聚焦回归163/163，学生专用浏览器4/4；后台相关轻量回归49项通过。与上面有重合，不相加成为总量。
- 另外执行CI的32组离线单元/组件命令：首轮30组通过；question-ticket-test只因安全预载不理解已注入的require.cache假DB而阻止，读取测试证明固定合成JWT与内存假DB后，在无预载独立进程复跑通过，无数据库初始化；旧后台真实浏览器暴露手机遮罩层级，修复后46项通过。最终32组对应检查均有通过证据。
- 原Word真实浏览器130项、公式键盘真实浏览器检查通过。旧后台46项包含实际抽屉开合/菜单点击、对话框和表单几何。

测试fixture调整没有删除生命周期/权限/提交保护断言：课程侧栏断言改为新顶部导航；错题新版tab宿主/真实optText辅助；生命周期空态断言增强为刷新前1题、刷新后0题且旧题消失；后台面包屑随真实TITLE；答题栏宽度及行高匹配新设计。
