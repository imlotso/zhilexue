## 复现、测试与审查

最初 11 项浏览器检查记录了登录、空学科入口、1180px 页脚溢出、两处公式预览、学生反馈公式、任务刷新、旧导入筛选和成绩标题 320px 留白的失败。词汇用例起初因首次进入的正常路由跳转而未到目标页；补足合成词书并从课程页正常进入后，以基线 `words.js` 实际复现错误高亮，随后通过修复。没有把测试前置条件错误算作产品缺陷。

独立只读代码审查发现 4 个需要补足的边界：纯上下标答案、报告 × 退出、遗漏的采集/识别工作台导航，以及键盘宿主参与 flex 后挤窄弹窗。逐项新增失败用例后修复；最终变更未二次独立代码审查，后续由用户安排的 Astra 复测仍须执行。

最终本地 **72 个脚本退出 0**（现有 CI 70 个 + 新增定向浏览器脚本 + 单词布局脚本），其中定向浏览器 **18/18**、单词布局 **34/0**。新增键盘实际点击检查初次定位到了隐藏模板，修正测试定位后重跑 18 项通过，详见记录的首次尝试与最终结果。最新逐脚本退出状态与定向浏览器结果见 `test-results-browser-audit-20261106.json`。脚本退出 0 只证明其断言和样本通过；原测试内的可选模板与部署包跳过项保留，未作通过统计。全后台视口截图也不等于真机、全部业务和 93 项需求全部通过。
