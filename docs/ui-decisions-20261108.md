# UI 实施取舍

1. 概念图作为布局、层级、颜色和图形依据。所有业务值仍来自现有数据；图中示例的日期、进度、任务、题目、老师身份不进入生产代码。
2. 新首页保留旧课程页路由，避免把学习门户重构成新的业务实现。新增首页请求通过账户和页面快照隔离迟到响应。
3. AI 桌面停靠在答题卡下方，手机以抽屉展示。未核对题目显示锁定态；仅打开面板不请求 AI。收起、关闭、切题、重练后仍可恢复入口。
4. 原解析及反馈功能保留。重复的作答/参考答案收在原生 details 中，选项正确/错误仍同时用颜色、图标和文字表达。
5. 后台没有独立的“分类确认”接口，因此按钮采用“保存分类”，教材/章节显示真实已存值，最终目录归属仍在原“核对并入库”确认框内处理。不会仿制本地假确认状态。
6. 后台额外来源、图片、AI、合并和批量工具收在可展开区；未保存分类阻断切换/刷新/批量入库，提供明确撤销入口。入库沿用原服务端检查。
7. 本次源自核验过的安全源码快照，完整部署树含独有配置及历史文档。只生成增量补丁，不执行部署覆盖或远程写入。
