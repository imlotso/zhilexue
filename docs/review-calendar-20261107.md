# 错题复习日历日期修复

基线：0358baa + v3 + Node20兼容 + 手动错误提示 + R9异步动作 + 小学年级补齐v2。单独增量，不改此前冻结目录。

## 已确认缺陷

src/bank.js的addDays把日期改成斜线格式后再添加T00:00:00，Node实际返回Invalid Date，结果可变成NaN-NaN-NaN。public/js/bank.js的ageDays使用同一错误格式，解析失败回退0，旧错题可能全落在2天内。

改用标准ISO日期部分加本地午夜，不将时间戳硬加24小时。原本的1/2/4天安排不变，跨月、跨年、闰年和夏令时仍按日历计算。前端>180天错题归历史，避免同时出现在8–180强化组。

没有读取或更改真实学生记录，没有修复已存的非法next_review值。上线前宜在备份/隔离副本中只读统计异常日期并确认修复策略；不能推断当前真实库一定有异常或直接批量覆盖。日期计算与界面分桶已离线验证，HTTP提交事务、MySQL实际持久化、浏览器和真机没有新增验收证据。
