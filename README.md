# 智学课堂 · 学习系统

一套面向中小学的学习系统，包含 **学生端**、**校长后台** 和 **分校后台** 三部分（线上地址 zhilexue.top）。
学生端做三类事：**看视频、做题（课文习题 / 试卷 / 错题本）、背单词**；老师在后台管理课程、题库、试卷和学情。

| 端    | 地址                   | 说明                                                                                                         |
| ---- | -------------------- | ---------------------------------------------------------------------------------------------------------- |
| 学生端  | `http://你的域名/`       | 学科（数学/英语/物理/化学）→ 课程分类 → 课程卡片 → 课程页（视频 + 讲义 + 课文习题），另有试卷库、错题本、速记（单词）、学习报告 |
| 校长后台 | `http://你的域名/admin/` | 学生与账号、教学资源、智能题库（含待审核、知识树、组卷、试卷管理）、学情与报告、系统设置（AI 配置中心）                                |
| 分校后台 | 同一地址 `/admin/`       | 与校长端功能一致（无分校管理 / 操作日志入口），由校长开通                                                                             |

技术栈：Node.js + Express + **MySQL** + 原生前端（学生端 Vue 3 全局构建、后台 Vue 2 + element-ui，**没有构建步骤**，改完刷新即生效）。

## 一、本地快速运行

需要 Node.js 20（CI 用的版本）和一个 MySQL（或 MariaDB）。

```bash
npm install          # 首次运行，安装依赖；保留 optional 依赖，Word 公式图片需要平台原生库
npm run seed         # 初始化数据（校长账号 / 示例课程目录 / 示例学生 / 词书示例）
npm start            # 启动服务，默认 http://localhost:3000
```

**数据库连接**：读取顺序为 环境变量（`MYSQL_HOST` / `MYSQL_PORT` / `MYSQL_USER` / `MYSQL_PASSWORD` / `MYSQL_DATABASE`）→ `src/config.local.js`（默认 `127.0.0.1:3306`，库名 `xuexi`）。建表和加列在启动时由 `src/db.js` 幂等完成，不需要手工执行 SQL；库为空时会尝试从 `data/xuexi.db`（旧版 SQLite 文件）导入。

打开浏览器：

- 校长后台 <http://localhost:3000/admin/>　账号与密码由部署者配置；隔离测试使用单独的临时账号。
- 学生端 <http://localhost:3000/>　账号 `13800000001`　密码 `123456`（学生账号只能由校长 / 分校后台开通）

> ⚠️ 服务必须保持运行才打得开网页。同一局域网内的手机 / 其他电脑可以用 `http://本机IP:3000/` 访问（需放行 3000 端口）。
> 生产环境请务必修改默认密码、`JWT_SECRET`、`DEL_PWD`（见下文环境变量）。

**没有真实的 AI Key / 语音合成时**：启动时加 `AI_MOCK=1`（AI 请求返回演示数据，不调外部接口）和 `TTS_MOCK=1`（文字生成朗读返回一段占位音频），并用 `STORAGE_DRIVER=local` 把文件存本地磁盘。CI 就是这样跑的：

```bash
STORAGE_DRIVER=local AI_MOCK=1 TTS_MOCK=1 npm start
```

**AI 请求代理**：可按目标协议设置 `HTTP_PROXY` / `HTTPS_PROXY`，并用 `NO_PROXY` 排除不需要代理的域名；同时识别小写变量。`localhost`、`.localhost` 与回环 IP 始终直连。代理仅用于 AI 客户端的普通与流式请求，不改变其他网络请求；TLS 证书校验保持开启。需要信任额外 CA 时，可使用 Node.js 的 `NODE_EXTRA_CA_CERTS` 指向证书文件。

### 第一次使用的推荐顺序

1. 后台 **教学资源 → 课程目录** → **新增章节**：依次选 ① 学科 → ② 年级 → ③ 课程分类，再自己填写 ④ 章节名称。**一条目录 = 学生端的一门课程**，目录里的每个视频就是一个「知识点」。
2. （可选）在章节下「**+ 分级目录**」添加小节（如「1.1 正数与负数」），上传视频 / 讲义时可以选归到哪个小节，学生端课程页会折叠成一层。
3. **视频管理** → 「⬆ 批量上传视频」（每个文件 = 一个知识点），或「🔗 添加外链视频」填 B 站 / 腾讯视频 / OSS 直链。
4. **讲义资料** → 上传资料：关联了某个视频就是该知识点的「打印讲义」；没有关联视频则进入该课程的「本章习题库」。
5. **学生与账号 → 学生管理** → 开通学生账号（账号 + 密码 + 年级 + 学段），按需切换「倍速播放」「视频快进」开关。
6. **智能题库**：先在「知识树管理」里确认章节树和知识点树，再用「题库管理 / 待审核题目」录题，用「智能组卷」组卷并下发给学生；给视频绑定课文习题见「课文习题」。
7. 用学生账号登录学生端，按学科进入课程，播放视频、做练习、做试卷、看错题本。

## 二、功能清单

**学生端**

- 账号密码登录（账号只能由校长/分校后台开通，学生端没有注册入口）
- 一级目录（左侧固定）：**数学 / 英语 / 物理 / 化学**，四科独立配色；化学下方还有 **试卷** 与 **错题本** 两个入口
- 二级目录（顶部）：**同步基础 / 同步培优 / 专项提升 / 中考冲刺**，标签上显示该分类下的课程数
- 课程卡片：一张卡片 = 一门课程，底部是**知识点学习进度条**（已学 / 总知识点 + 百分比）
- 课程页：每个知识点一个框 = 视频 + 配套讲义 + **配套练习**，按钮有「▶ 播放视频」「🖨 打印讲义」「✏️ 练习」；
    
  视频看到 90% 或播放结束自动记为已学；练习做完自动判分，**做错的题自动进错题本**
- **做练习（在线做题）**：支持 单选 / 多选 / 判断 / 填空（多空、备选答案）/ 排序·连词成句，完形填空与阅读理解按「原文 + 小题」呈现；交卷即时判分并展示每题答案与解析，可整组重做
- **试卷**：老师组好下发的试卷按年级 / 学段自动匹配出现，在线作答、交卷出分，错题同样进错题本
- **错题本**：按 英语 / 数学 / 物理 / 化学 分类，记录错次、我的答案、正确答案与解析；单题重做（答对自动移出）、标记掌握 / 恢复
- 本章习题库：每门课程可挂多套习题，支持在线预览、打印、下载
- **速记（左侧第一目录，全屏弹层）**：单词速记、短语速记、词性训练、语境记忆、连词成句、**考纲单词**、指法练习。
    
  词书由后台「AI单词训练」上传表格 / AI 生成，全体学生可见；每次作答自动计入训练统计，答错的自动进错词本 / 错句本可一键重练。
    
  其中**考纲单词**与单词速记共用同一批词书，但不按单元划分，也不用默写：整本书先筛「会 / 不会」（卡片过筛或列表勾选），
    
  认识的标「已会」直接跳过，再自己选每组 5 个或 10 个，把待学的词切成小组，走「单词识记 → 学后检测 → 抗遗忘复习」的识记流程——
    
  全程只做识记题（看英选义 / 看义选英 / 听音辨义），每个词连认 2 遍、答错的自动多认一遍，认对的自动移出错词本。
- 打印讲义 / 习题：PDF / 图片 / 网页 / TXT 直接全屏预览并一键打印；Word / PPT 等自动转为下载
- 学习报告（右上角）：已学知识点、整体完成率、已看讲义、累计学习天数、总进度条、分学科进度、最近 14 天学习曲线、最近学习记录
- 视频倍速：由老师在后台按学生开启/关闭；开启后播放器提供 `0.75 / 1.0 / 1.25 / 1.5 / 2.0` 五档，关闭时锁定 1.0 倍速
- 视频快进：由老师在后台按学生开启/关闭（默认允许）；关闭后拖动进度条向前跳转会被自动拉回并提示「老师未开启快进」，回看已学过的部分不受影响
- 多端自适应：电脑 / 平板 / 手机浏览器直接打开网址即可使用。平板下侧栏收窄、卡片自适应排布；手机端学科目录自动变为**底部导航**，右上角「学习报告」收为图标，头像点开「改密码 / 退出」菜单，播放器与打印预览全屏化；输入框 16px 避免 iOS 聚焦缩放，适配 iPhone 底部安全区
- 修改密码

**校长后台**

- 数据概览：学生总数 / 讲义 / 习题 / 视频 / 课程目录 + 快捷操作 + 最近开通的学生
- 分校管理（仅校长）：开通分校账号、停用/启用、重置密码、删除，并显示各分校已开通学生数
- 学生管理：开通 / 编辑 / 重置密码 / 停用 / 删除、**批量开通**、**倍速播放一键开关**、**视频快进一键开关**（编辑弹窗内可同时设置两项）
- 课程目录：按「一级 学科 → 二级 课程分类 → 三级 课程目录」分组展示，与学生端结构一一对应；支持学科/年级/分类筛选
- 级联选择：批量上传视频 / 添加外链视频 / 上传讲义与习题 / 重新关联资料，全部使用「① 学科 → ② 课程分类 → ③ 课程目录」三级级联选择，不再出现长长的混排下拉；视频管理与讲义与习题两个列表页同样使用三级级联筛选
- 讲义与习题：上传时选「所属目录 + 是否关联视频」——**关联了视频就是讲义，不关联就进本章习题库**；
    
  列表可按去向筛选、支持「关联」重新绑定、下载、删除；**删除（单个 / 批量）需输入删除密码**，支持勾选**批量删除**
- **AI单词训练（两个子模块）**：📚**词书管理**（选词书 / 新建删除 / 上传表格 / AI 补全 / AI 生成词库 / 四库管理，
    
  当前词书显示 学习人数 / 作答次数 / 最近作答）、📈**学生学习进度**（每个学生在速记 6 个模块的作答统计（对/总）、
    
  训练词书、**分组完成明细**——学生端练完四步自动上报；校长可按 总校 / 各分校 筛选，分校账号只能看自己开通的学生）
- 视频管理：**批量上传**（一次选多个文件，每个文件 = 一个知识点）或添加外链，按目录筛选，可预览；**删除（单个 / 批量）需输入删除密码**，支持勾选**批量删除**
- **错题重组**：外接摄像头 / 上传照片扫描试卷 → 自动去阴影、裁边、**按空白自动切题**（分割线可拖动微调、可合并/加线）
    
  → 勾选题目 → 一键生成**双栏 A4 错题集 PDF**（带中文页眉、题号、页码），在线预览 / 下载 / 打印。
    
  题目按批次积累在题库里，可跨批次勾选反复出卷。（原 `docs/错题重组使用说明.md` 未随本仓库提供）
- **智能题库**（后台左侧「智能题库」，详见下面「改版新增」）：**题库管理**（按学段 + 学科 + 年级 + 章节 / 知识点分类，单题录入 / 编辑、批量操作、Excel 九类题型模板与 Word 导入、网络采集、录题上传、错题反馈）、**待审核题目**（所有录题入口先到这里逐题核对再入库）、**知识树管理**、**试卷管理**（真题 Word 上传入库、试卷库）、**智能组卷**（章节组卷 / 知识点组卷，下发到学生端）、**课文习题**（给视频绑题，学生端课程页【做练习】）。
- **学情与报告**：成绩管理、谈心谈话、家校沟通、AI 学情诊断（「学习报告」在「学生与账号」下，词书 / 视频 / 习题 / 错题四个页签，习题页签的详情里有课程 → 小分组 → 视频正确率）；错题可按学生导出 Word / 打印。

**课程分类（4 科统一 4 大类，可在 `public/admin/admin.js` 的 `CATEGORIES` 调整名称）**

| 学科                | 分类                  |
| ----------------- | ------------------- |
| 数学 / 英语 / 物理 / 化学 | 同步基础、同步培优、专项提升、中考冲刺 |

**关于做题**：线上做题：每门课程除可打印的「**习题库**」文件外，还支持**在线做题**——课程页知识点处的【做练习】（管理端课文习题里绑定到视频的题）、左侧栏【试卷】（智能组卷下发的试卷）与【错题本】（做错的题自动按学科归集，可重做、可标记"我会了"移出）。
  
老版本数据库里的分类名（同步学 / 培优学 / 技巧课 / 语法 / 专项课）会在 `npm run seed` 时自动迁移到新的 4 大类。

**2026-11 改版新增 / 调整的能力**（细节与取舍见 `docs/changelog-20261107.md`、`docs/decisions.md`）

- **知识树统一**：章节树（教材 → 册 → 单元 …）+ 知识点树，后台「智能题库 → 知识树管理」可编辑；题目可同时挂章节和知识点；旧知识点数据用 `scripts/migrate-kb-to-trees.js` 迁入（先在测试库预演）。
- **待审核题目**：Excel / Word / 拍照识别 / 技能包 / 网络采集 / 手机扫码，所有录题入口先进「待审核题目」，每道题标注来源，逐题核对（可补音频、改答案；AI 答案与解析须老师逐项确认）后再入库。
- **组卷与下发**：「章节组卷 / 知识点组卷」两种方式（后台智能组卷、学生端自组卷共用同一套抽题逻辑），老师可把试卷定向下发给指定学生。
- **课文习题与正确率**：课文习题输入框固定；学习报告按视频、按小分组统计正确率；后台「学生与账号 → 学习报告 → 习题学习报告 → 详情」按学生查看（原「知识点正确率」页已并入，旧地址 `#/acc` 会跳转）。
- **AI 配置中心**：后台「系统设置 → AI 配置中心」是全站唯一的 AI 入口，按「文本生成 / 图像识别」分档案，支持 OpenAI 兼容 / Anthropic / Gemini 三种格式，配置 → 测试 → 启用即全站生效；没有启用档案时回退内置配置。
- **错题本改版与 Word 导出**：学生端错题本去掉「收藏」，按学科 / 状态 / 时间筛选后可导出**可编辑的 .docx**（含题图、答案、解析、作答记录）；学生端「手机扫码上传」错题进入待审核。
- **试卷管理**：上传真题 Word → 识别预览 → 一步生成试卷并入题库；学生端试卷库可按关键字、年份、年级搜索。
- **听力题**：给现有题型附加音频（后台上传，或「用文字生成朗读」），学生端题目上方出现播放条；音频存 `bank/audio/`。
- **公式输入**：后台录题（题干 / 选项 / 答案 / 解析）和学生端数学 / 物理 / 化学的填空、问答题都可以用 MathLive 公式键盘（本地文件，不走 CDN）；公式以 `\( … \)` 存储，学生端 MathJax 渲染；判分不做公式等价。
- **Word 公式导出**：常见分式、根式和上下标生成可编辑公式；其他可识别公式在服务端使用 MathJax 和 resvg 生成 PNG。无法识别、需要系统字体或超出资源限制的公式保留 LaTeX 原文，供人工核对；公式图片不可编辑。
- **题库与视频分类存放**：题库资源统一在 `bank/`，视频在 `videos/`，只通过绑定关系关联，删除视频不删题；两类资源不需要独立存储桶。
- **学生端单词页固定布局**：学习卡片固定高度，长单词 / 长释义自动缩字号，不再跳动。
- **后台 UI 统一**：`public/admin/theme.css`（全部挂在 `body.t11` 下）统一按钮 / 表格 / 表单 / 弹窗；左侧菜单分为 学生与账号 / 教学资源 / 智能题库 / 学情与报告 / 系统设置，手机宽度下侧栏是抽屉。

### 题库与视频分类存放

题目的图片、音频、导入附件统一放在存储的 `bank/` 目录下（子目录 `img` 题目图、`audio` 听力音频、`recog` 录题页图、`paper` 导出试卷），**视频放 `videos/`**，两类资源只靠 key 前缀区分；视频和题目只通过「绑定」（`videos/:id/bind`）关联，删除视频只会把题目解绑，不会删题。

已确认无需拆分物理存储桶，也不需要迁移现有文件。新题图使用稳定的文件代理地址；服务端识别当前配置的存储域名下的历史题图地址，并按对象 key 在访问时重新签发。无法归属到当前存储配置的历史外链会保留原样，需要核对其原始存储位置。
