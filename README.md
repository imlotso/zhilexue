# 智学课堂 · 学习系统

一套可直接部署到阿里云的中小学学习系统，包含 **学生端**、**校长后台** 和 **分校后台** 三部分。  
学生端只做三件事：**看视频**、**打印/下载讲义**、**做本章习题库**，没有线上做题，界面简洁不拥挤。

| 端    | 地址                   | 说明                                                                                                         |
| ---- | -------------------- | ---------------------------------------------------------------------------------------------------------- |
| 学生端  | `http://你的域名/`       | 一级目录学科（数学/英语/物理/化学）→ 二级目录课程分类（4 大类）→ 课程卡片（知识点学习进度条）→ 课程页（可按「分级目录」折叠分组，一个知识点 = 一个视频 + 一份讲义，另有本章习题库），右上角学习报告 |
| 校长后台 | `http://你的域名/admin/` | 分校管理、学生账号（含倍速开关）、课程目录、讲义与习题、视频                                                                             |
| 分校后台 | 同一地址 `/admin/`       | 与校长端功能一致（无分校管理入口），由校长开通                                                                                    |

技术栈：Node.js + Express + SQLite + 原生前端（无构建步骤，改完刷新即生效）。

## 一、本地快速运行

**方式一（最简单，Windows）**：双击项目根目录的 `start.bat`，会自动启动服务并显示地址，关掉黑窗口即停止服务。

**方式二（命令行）**：

```bash
cd xuexi-system/server
npm install          # 首次运行，安装依赖
npm run seed         # 初始化数据（校长账号 / 示例课程目录 / 示例学生）
npm start            # 启动服务
```

打开浏览器：

- 校长后台 <http://localhost:3000/admin/>　账号 `15152099970`　密码 `123456`
- 学生端 <http://localhost:3000/>　账号 `13800000001`　密码 `123456`（学生账号只能由校长/分校后台开通）

> ⚠️ **服务必须保持运行才打得开网页**：关闭命令行/黑窗口、重启电脑后，网站就打不开了，重新双击 `start.bat` 启动即可。>   
> 同一个局域网内的手机 / 其他电脑可以用 `http://本机IP:3000/` 访问（本机 IP 用 `ipconfig` 查看，例如 `http://192.168.1.121:3000/`）；若访问不了，在 Windows 防火墙里放行 Node.js 或 3000 端口。

> 生产环境请务必修改默认密码；后台账号密码可在数据库 `users` 表中调整。

### 第一次使用的推荐顺序

1. 后台 **课程目录** → **新增章节**：依次选 ① 学科 → ② 年级 → ③ 课程分类，再自己填写 ④ 章节名称（可加一个「二级名称」副标题，显示在学生端章节卡片副标题位置）。     
   **一条目录 = 学生端的一门课程**，目录里的每个视频就是一个「知识点」。
2. （可选）回到 **课程目录**，在章节下「**+ 分级目录**」添加小节（如「1.1 正数与负数」）。     
   设了分级目录后，上传视频 / 讲义时可以选归到哪个小节，学生端课程页会把这些内容**折叠成一层，点击标题才展开**；不设置则学生端直接平铺展示
3. 后台 **视频管理** → 「⬆ 批量上传视频」一次选多个文件（每个文件 = 一个知识点，标题默认用文件名，可加前缀，并选择归属的分级目录）；     
   也可以「🔗 添加外链视频」直接填 B 站 / 腾讯视频 / OSS 直链     
   上传后可点视频行的「编辑」改名或调整所属章节 / 分级目录（学生端实时同步）
4. 后台 **讲义与习题** → 上传资料：
   - **关联了某个视频** → 学生端在对应知识点里显示「🖨 打印讲义」（和视频在同一个框里）
   - **没有关联视频** → 自动进入学生端该课程的「**本章习题库**」
   - 随时点列表里的「关联」可以重新绑定或摘下来
5. 后台 **学生管理** → 开通学生账号（账号 + 密码 + 年级），按需切换「倍速播放」开关
6. 用学生账号登录学生端 → 选学科、选分类 → 点课程卡片进入，播放视频 / 打印讲义 / 做习题库

## 二、功能清单

**学生端**

- 账号密码登录（账号只能由校长/分校后台开通，学生端没有注册入口）
- 一级目录（左侧固定）：**数学 / 英语 / 物理 / 化学**，四科独立配色；化学下方还有 **试卷** 与 **错题本** 两个入口
- 二级目录（顶部）：**同步基础 / 同步培优 / 专项提升 / 中考冲刺**，标签上显示该分类下的课程数
- 课程卡片：一张卡片 = 一门课程，底部是**知识点学习进度条**（已学 / 总知识点 + 百分比）
- 课程页：每个知识点一个框 = 视频 + 配套讲义 + **配套练习**，按钮有「▶ 播放视频」「🖨 打印讲义」「✏️ 练习」；    
  视频看到 90% 或播放结束自动记为已学；练习做完自动判分，**做错的题自动进错题本**
- **做练习（在线做题）**：支持 单选 / 多选 / 判断 / 填空（多空、备选答案）/ 排序·连词成句，完形填空与阅读理解按「原文 + 小题」呈现；交卷即时判分并展示每题答案与解析，可整组重做
- **试卷**：老师组好下发的试卷按年级 / 学段自动匹配出现，在线作答、交卷出分，错题同样进错题本
- **错题本**：按 英语 / 数学 / 物理 / 化学 分类，记录错次、我的答案、正确答案与解析；单题重做（答对自动移出）、标记掌握 / 恢复
- 本章习题库：每门课程可挂多套习题，支持在线预览、打印、下载
- **速记（左侧第一目录，全屏弹层）**：单词速记、短语速记、词性训练、语境记忆、连词成句、**考纲单词**、指法练习。    
  词书由后台「AI单词训练」上传表格 / AI 生成，全体学生可见；每次作答自动计入训练统计，答错的自动进错词本 / 错句本可一键重练。    
  其中**考纲单词**与单词速记共用同一批词书，但不按单元划分，也不用默写：整本书先筛「会 / 不会」（卡片过筛或列表勾选），    
  认识的标「已会」直接跳过，再自己选每组 5 个或 10 个，把待学的词切成小组，走「单词识记 → 学后检测 → 抗遗忘复习」的识记流程——    
  全程只做识记题（看英选义 / 看义选英 / 听音辨义），每个词连认 2 遍、答错的自动多认一遍，认对的自动移出错词本。
- 打印讲义 / 习题：PDF / 图片 / 网页 / TXT 直接全屏预览并一键打印；Word / PPT 等自动转为下载
- 学习报告（右上角）：已学知识点、整体完成率、已看讲义、累计学习天数、总进度条、分学科进度、最近 14 天学习曲线、最近学习记录
- 视频倍速：由老师在后台按学生开启/关闭；开启后播放器提供 `0.75 / 1.0 / 1.25 / 1.5 / 2.0` 五档，关闭时锁定 1.0 倍速
- 视频快进：由老师在后台按学生开启/关闭（默认允许）；关闭后拖动进度条向前跳转会被自动拉回并提示「老师未开启快进」，回看已学过的部分不受影响
- 多端自适应：电脑 / 平板 / 手机浏览器直接打开网址即可使用。平板下侧栏收窄、卡片自适应排布；手机端学科目录自动变为**底部导航**，右上角「学习报告」收为图标，头像点开「改密码 / 退出」菜单，播放器与打印预览全屏化；输入框 16px 避免 iOS 聚焦缩放，适配 iPhone 底部安全区
- 修改密码

**校长后台**

- 数据概览：学生总数 / 讲义 / 习题 / 视频 / 课程目录 + 快捷操作 + 最近开通的学生
- 分校管理（仅校长）：开通分校账号、停用/启用、重置密码、删除，并显示各分校已开通学生数
- 学生管理：开通 / 编辑 / 重置密码 / 停用 / 删除、**批量开通**、**倍速播放一键开关**、**视频快进一键开关**（编辑弹窗内可同时设置两项）
- 课程目录：按「一级 学科 → 二级 课程分类 → 三级 课程目录」分组展示，与学生端结构一一对应；支持学科/年级/分类筛选
- 级联选择：批量上传视频 / 添加外链视频 / 上传讲义与习题 / 重新关联资料，全部使用「① 学科 → ② 课程分类 → ③ 课程目录」三级级联选择，不再出现长长的混排下拉；视频管理与讲义与习题两个列表页同样使用三级级联筛选
- 讲义与习题：上传时选「所属目录 + 是否关联视频」——**关联了视频就是讲义，不关联就进本章习题库**；    
  列表可按去向筛选、支持「关联」重新绑定、下载、删除；**删除（单个 / 批量）需输入删除密码**，支持勾选**批量删除**
- **AI单词训练（两个子模块）**：📚**词书管理**（选词书 / 新建删除 / 上传表格 / AI 补全 / AI 生成词库 / 四库管理，    
  当前词书显示 学习人数 / 作答次数 / 最近作答）、📈**学生学习进度**（每个学生在速记 6 个模块的作答统计（对/总）、    
  训练词书、**分组完成明细**——学生端练完四步自动上报；校长可按 总校 / 各分校 筛选，分校账号只能看自己开通的学生）
- 视频管理：**批量上传**（一次选多个文件，每个文件 = 一个知识点）或添加外链，按目录筛选，可预览；**删除（单个 / 批量）需输入删除密码**，支持勾选**批量删除**
- **错题重组**：外接摄像头 / 上传照片扫描试卷 → 自动去阴影、裁边、**按空白自动切题**（分割线可拖动微调、可合并/加线）    
  → 勾选题目 → 一键生成**双栏 A4 错题集 PDF**（带中文页眉、题号、页码），在线预览 / 下载 / 打印。    
  题目按批次积累在题库里，可跨批次勾选反复出卷。详见 `docs/错题重组使用说明.md`
- **智能题库（教学资源与训练管理之间的大模块，四个子页）**：
  ① **题库管理**——题目按 学段（小学 / 初中）+ 学科 + 年级 + 知识点 划分，支持单题录入、编辑、绑定视频、删除；支持 **Excel 九类题型模板批量导入**（单选 / 多选 / 判断 / 组合 / 填空 / 排序 / 完形填空 / 选择填空 / 阅读理解，可下载模板），复合题按小题拆行入库
  ② **智能组卷**——按 学科 + 年级 + 学段 + 知识点 + 各题型数量 一键随机抽题组卷，预览时可移除个别题目再补抽；试卷保存草稿 → **下发到学生端【试卷】页**（按年级 / 学段自动匹配可见），可撤回、编辑、删除
  ③ **课文习题**——按 教学资源目录选择课本 → 左侧分组 → 右侧视频列表（显示每个视频已绑题数）→ 给视频添加习题或从题库批量选择绑定；**绑定到视频的题会出现在学生端课程页的【做练习】按钮里**
  ④ **错题记录**——按 学生 / 学科 / 状态 筛选查看单个学生的全部错题（分校账号只能看本校区学生），支持 **A4 打印纸质化**（题目在前、参考答案与解析在末尾）

**课程分类（4 科统一 4 大类，可在 `public/admin/admin.js` 的 `CATEGORIES` 调整名称）**

| 学科                | 分类                  |
| ----------------- | ------------------- |
| 数学 / 英语 / 物理 / 化学 | 同步基础、同步培优、专项提升、中考冲刺 |

**关于做题**：线上做题：每门课程除可打印的「**习题库**」文件外，还支持**在线做题**——课程页知识点处的【做练习】（管理端课文习题里绑定到视频的题）、左侧栏【试卷】（智能组卷下发的试卷）与【错题本】（做错的题自动按学科归集，可重做、可标记"我会了"移出）。  
老版本数据库里的分类名（同步学 / 培优学 / 技巧课 / 语法 / 专项课）会在 `npm run seed` 时自动迁移到新的 4 大类。

## 四、上线部署

### 先看情况选路线

| 你的情况                            | 该看哪份文档                                              |
| ------------------------------- | --------------------------------------------------- |
| **第一次上架，想要一份从买服务器到上线的完整清单**     | **`docs/上架全流程手册.md`** ← 推荐先看这份                      |
| 内容量不大（几十 GB 以内）、同时在用的人少（20 人以内） | **`docs/新手上架教程-宝塔面板版.md`** 直接照着做即可                  |
| **内容上百 GB、或同时几十人在线看视频**         | 先看 **`docs/采购与成本方案-500G内容60人并发.md`** 决定买什么，再按上架教程部署 |

> 一句话原则：**视频不要放服务器硬盘、不要走服务器带宽**。内容放对象存储 OSS，用 CDN 分发给学生，服务器只跑程序。这样才有稳定的观看体验和可控的成本。

### 题库资源独立存储（预留，未启用）

题目的图片、音频、导入附件统一放在存储的 `bank/` 目录下（子目录 `img` 题目图、`audio` 听力音频、`recog` 录题页图、`paper` 导出试卷），**视频放 `videos/`**，两类资源只靠 key 前缀区分；视频和题目只通过「绑定」（`videos/:id/bind`）关联，删除视频只会把题目解绑，不会删题。

所以将来想把题库资源迁到单独的 Bucket（例如换一个访问更快 / 更便宜的存储），不需要改数据库，步骤是：

1. 在新 Bucket 里建好同名的 `bank/` 目录，用 `ossutil cp -r` 把旧 Bucket 的 `bank/` 整个拷过去（key 不变）。
2. 设置环境变量 `BANK_BUCKET=<新 Bucket 名>`。`src/storage.js` 的 `bucketFor(key)` 会对 `bank/` 开头的 key 返回它、其它 key 返回空（默认桶）。
3. 在 `storage.js` 的 `saveFile` / `getUrlSync` / `deleteFile` 里按 `bucketFor(key)` 选择对应的 OSS client（再 new 一个指向新 Bucket 的 client）。**这一步目前没有实现**，因为现在题库和视频在同一个 Bucket，没有切换的需要。

> 注意：题目的图片地址是录入时生成并存进题目里的（OSS 无 CDN 时是 1 小时有效的签名链接）。迁移或拆桶前，先看 `docs/pending-human-actions.md` 里「题目图片地址有效期」一条。
